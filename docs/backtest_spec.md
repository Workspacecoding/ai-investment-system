# Backtest Spec

Backtests evaluate strategy modules against historical data.

Core requirements:

- Fixed strategy version and parameter set.
- Point-in-time data access.
- Transaction cost and slippage assumptions.
- Position sizing rules.
- Entry, exit, and rebalance logic.
- Benchmark comparison.

Metrics:

- CAGR.
- Max drawdown.
- Sharpe ratio.
- Win rate.
- Profit factor.
- Turnover.
