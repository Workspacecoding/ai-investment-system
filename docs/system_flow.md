# System Flow

1. Ingest account, market, ETF, industry, news, and price data.
2. Normalize raw data into a research universe.
3. Calculate indicators, price levels, risk metrics, and scoring signals.
4. Generate strategy recommendations and trade plans.
5. Run goal, profit, and portfolio impact checks.
6. Deliver dashboard views, reports, newsletters, and optional broker actions.
7. Record outcomes for performance tracking and backtesting feedback.
